# 生活与职业方向探索

这是一个 Codex skill，用于陪伴想改变生活现状或探索职业方向的人，通过一次一个问题的对话，逐步澄清愿望、卡点、资源与支持。

## Skill 标识

- Skill ID: `personal-direction-dialogue`
- 主文件：`SKILL.md`
- 界面元数据：`agents/openai.yaml`
- 可选追问示例：`references/question-patterns.md`

## 使用

在支持 Codex skills 的环境中引用 `personal-direction-dialogue`，或直接阅读 `SKILL.md` 了解完整规则。

仓库地址：<https://github.com/Nancyxu886/personal-direction-dialogue-skill>
