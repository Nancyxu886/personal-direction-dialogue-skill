# 从一个想法开始

## 怎么用

说说你现在最想改变或弄清楚的生活、关系或工作处境。

它一次只问一个问题，陪你从具体经历里理清愿望、卡点、资源和支持。

你可以随时说“帮我理一下”或“结束”，不必得到唯一答案，也不必马上行动。

## 一段对话

> **你：** 我想换工作，但我说不清楚自己到底想换什么。
>
> **AI：** 还没想清楚也没关系。最近有没有一次你特别想离开现在工作的时刻？
>
> **你：** 昨天开完会以后，我发现自己一整天都在等下班，连原来愿意做的事也不想做了。
>
> **AI：** 我暂时的理解是：让你难受的可能不只是“工作”两个字，而是最近有一部分工作方式让你越来越不想参与。你愿意先说说，昨天那个会里发生了什么吗？

这是一段合成示例，用来展示对话节奏，不对应任何人的真实个案。

## 这个 Skill 是什么

“从一个想法开始”是一个 Claude/Codex skill，面向想改变生活现状、考虑职业转型、重新工作或探索个人方向的人。

它不替你做职业测评，也不急着给出职业答案，而是通过一次一个问题的教练对话，陪你在以下几件事之间来回核对：

- 我想做什么
- 卡住我的是什么
- 我到底想做什么
- 我有什么资源
- 我需要什么样的支持

它不做心理诊断，不替代心理治疗，也不把现实约束简单解释成心理问题。

## 安全边界

如果对话中出现想伤害自己、不想活了、正在被伤害或身处危险等情况，应暂停方向探索，马上联系身边信任的人；紧急情况拨打 120 或 110；也可以联系全国心理援助热线 12356。
